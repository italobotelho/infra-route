InfraRoute

Contexto

Provedores de internet regionais ou empresas de telocomunicações privadas gastam milhões de reais ao expandir sua infraestrutura de cabos de fibra óptica. Muitas vezes criam redes redundantes, sobrepostas e mal otimizadas, o que gera desperdício de material e aumento desnecessário nos custos de implantação.

Objetivos

Criar um sistema web interativo onde os engenheiros inserem novos bairros ou pontos de interesse. O algoritmo calcula a estrutura matemática exata que gasta a menor quantidade de cabeamento possível para conectar todos os nós, desenhando a malha de rede na interface web.

Justificativa da escolha

O projeto atende empresas privadas de telecomunicações que buscam otimizar seus custos operacionais e expandir seus serviços de forma eficiente e de forma competitiva no mercado, atuando diretamente no ODS 9 (Indústria, Inovação e Infraestrutura).

O sistema também reduz drasticamente os custos operacionais de empresas otimizando rotas e evitando o uso e descarte excessivo de cabeamento e insumos plásticos e metálicos na natureza.

Metodologia

Uaremos técnicas de Ciência de Dados para extrair, limpar e estruturar os dados abertos para assim aplicarmos a Teoria dos Grafos (cálculo de árvore geradora mínima) no back-end.

O sistema transforma um planejamento manual suscetível à erros em um processo automatizado, garantindo matematicamente a construção da rede mais barata e sem redundâncias.

Estrutura técnica

A priori, será utilizada uma arquitetura em camadas contendo o front-end web para interface/mapas, back-end em linguagem Python isolando o processamento matemático do grafo via API, e um banco de dados relacional para persistência de projetos e usuários.

Desenvolveremos um modelo conceitual que será documentado via Diagrama Entidade e Relacionamento (DER) e o banco de dados fará uso de extensões geoespaciais para conseguir armazenar e relacionar as coordenadas da malha com os dados transacionais.
